# Соционика

Русскоязычный визуальный справочник по соционике на Vue 3, Nuxt 4 и Nuxt UI.

## Локальный запуск

Требуется Node.js 24 и pnpm 11.

```bash
pnpm install
pnpm dev
```

## Проверка

```bash
pnpm typecheck
pnpm build
pnpm generate
```

## Публикация на Vercel

1. Добавьте репозиторий в GitHub или другой поддерживаемый Git-сервис.
2. Импортируйте репозиторий в Vercel; Nuxt определяется автоматически.
3. Создайте переменную окружения `NUXT_PUBLIC_SITE_URL` с полным публичным адресом без завершающего `/`, например `https://project.vercel.app`.
4. Выполните первый деплой. Последующие push в основную ветку будут публиковаться автоматически.

Текущее устройство и состояние проекта описаны в [PROJECT_PASSPORT.md](./PROJECT_PASSPORT.md). Правила для работающих с репозиторием агентов находятся в [AGENTS.md](./AGENTS.md).

# Паспорт проекта «СоциоНавигатор»

Обновлено: 12 августа 2026 года.

## Цель продукта

Русскоязычный образовательный сайт-справочник по соционике: объяснять базовые понятия, показывать все 16 социотипов и давать удобную сравнительную таблицу первых четырёх функций модели А.

Основная аудитория — люди, которые впервые знакомятся с соционикой или хотят быстро сверить расположение информационных элементов у разных типов.

## Актуальное воплощение

Статус: первая рабочая версия реализована и проверена локально. Проект к публикации на Vercel подготовлен, но ещё не опубликован.

### Техническая основа

- Vue `3.5.41`, Nuxt `4.5.2` и TypeScript `6.0.3`;
- Nuxt UI `4.10.0` как основная библиотека компонентов интерфейса;
- Tailwind CSS `4.3.3`, подключённый через Nuxt UI, и проектный слой CSS;
- Node.js `24.x`, pnpm `11.16.0`, lock-файл `pnpm-lock.yaml`;
- SSR-сборка Nuxt и пререндеринг всех публичных страниц;
- отдельная статическая генерация поддерживается командой `pnpm generate`;
- целевая площадка публикации — Vercel, совместимый Node.js зафиксирован в `package.json`;
- внешняя база данных и серверное хранилище не используются.

### Реализованные публичные маршруты

- `/` — вводная страница с краткой картой модели А, ключевыми числами и точками входа;
- `/types` — каталог всех 16 социотипов, группировка по четырём квадрам и локальный поиск;
- `/functions` — сравнительная матрица первых четырёх функций модели А для всех типов и легенда восьми элементов;
- `/about` — принципы проекта, инструкция по использованию и методологическая оговорка.

На всех страницах используется единая закреплённая шапка с вкладками и общий футер.

### Дизайн и поведение

- светлая монохромная система в оттенках серого, без чистого чёрного и цветных акцентов;
- сочетание системного гротеска и Georgia для заголовков;
- адаптивные сетки и мобильная горизонтальная навигация;
- таблица функций прокручивается по горизонтали, а первый столбец с позициями закреплён;
- учтены состояния клавиатурного фокуса и настройка `prefers-reduced-motion`;
- Nuxt UI используется через `UApp`, `UContainer`, `UButton`, `UCard`, `UBadge` и `UInput`.

### Модель данных

Единый типизированный набор находится в `shared/data/socionics.ts` и содержит:

- восемь информационных элементов: ЧИ, БИ, ЧС, БС, ЧЛ, БЛ, ЧЭ, БЭ;
- полные «чёрные/белые» и смысловые названия элементов;
- 16 социотипов с кодом, полным названием, псевдонимом и квадрой;
- позиции 1–4 модели А: базовую, творческую, ролевую и болевую.

Столбцы сравнительной таблицы соответствуют социотипам, строки — позициям функций.

### SEO

- содержимое страниц доступно в готовом HTML благодаря пререндерингу;
- для каждого маршрута заданы отдельные `title`, `description`, Open Graph, Twitter и canonical metadata;
- `@nuxtjs/sitemap` `8.3.4` генерирует `/sitemap.xml`;
- `@nuxtjs/robots` `6.1.4` генерирует `/robots.txt` со ссылкой на карту сайта;
- `lang="ru"` и светлая цветовая схема заданы глобально;
- фактический канонический адрес перед публикацией задаётся переменной `NUXT_PUBLIC_SITE_URL` без завершающего `/`.

Без переменной окружения сборка использует технический адрес `https://socionavigator.example`; он не предназначен для публичного деплоя.

### Git и эксплуатация

- основная ветка репозитория — `main`;
- исходники защищены `.gitignore`, правила окончания строк — `.gitattributes` и `.editorconfig`;
- секреты и локальная папка Vercel не отслеживаются;
- команды запуска, проверки и публикации описаны в `README.md`;
- `AGENTS.md` обязывает поддерживать этот паспорт в соответствии с фактическим состоянием проекта.

## Границы первой версии

В текущую версию не входят тест определения типа, личные кабинеты, база данных, комментарии, коммерческие функции и отдельные подробные страницы каждого типа. Эти возможности могут добавляться последующими этапами.

## Следующий шаг

Создать удалённый Git-репозиторий, импортировать его в Vercel и задать `NUXT_PUBLIC_SITE_URL` равным выданному адресу `*.vercel.app` или собственному домену. После первого деплоя проверить реальный `robots.txt`, `sitemap.xml` и canonical URL, затем добавить сайт в Google Search Console и Яндекс Вебмастер.
